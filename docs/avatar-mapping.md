# Отображение денежных аватаров

Внутренние идентификаторы расчётных правил не меняются. Пользовательское название, изображение и
утверждённое описание централизованно выбираются из `AVATAR_PRESENTATIONS` в
`src/money_profile_bot/services/avatar.py`.

| Правило | Денежный аватар |
|---|---|
| Управитель II дома в I или X доме | Вдохновительница |
| Управитель II дома во II или VI доме | Мастерица |
| Управитель II дома в III доме | Рассказчица |
| Управитель II дома в IV доме | Хранительница |
| Управитель II дома в V доме | Создательница |
| Управитель II дома в VII доме | Эстетка |
| Управитель II дома в VIII доме | Навигатор |
| Управитель II дома в IX доме | Проводница |
| Управитель II дома в XI доме | Муза |
| Управитель II дома в XII доме | Искательница |

Для ветки без домов используются стихии Венеры:

| Стихия | Денежный аватар |
|---|---|
| Огонь | Вдохновительница |
| Земля | Мастерица |
| Воздух | Рассказчица |
| Вода | Хранительница |

Совместимость сохранённых результатов поддерживает замены: Коммуникатор - Рассказчица,
Творец - Создательница, Эксперт - Мастерица, Стратег - Навигатор, Лидер - Вдохновительница,
Организатор - Хранительница, Наставник - Проводница, Исследователь - Искательница,
Визионер - Муза, Эстет - Эстетка.
