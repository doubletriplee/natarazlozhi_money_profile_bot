# Telegram-бот «Денежный потенциал»

Публичная AGPL-3.0 реализация Telegram-бота, который детерминированно рассчитывает
астрологический денежный профиль по локальной Swiss Ephemeris. В работающем приложении нет
LLM и вызовов OpenAI API.

## Возможности

- стартовый экран с иллюстрацией и описанием авторского метода без проверки 18+;
- анкета с ветками точного, примерного и неизвестного времени рождения;
- локальный поиск GeoNames `cities500` и IANA timezone, включая ввод `Россия, Москва`;
- Плацидус с безопасной веткой без домов для полярных широт и неоднозначного времени;
- бесплатная карточка денежного аватара и предложение раскрыть его силу через 4 секунды;
- фиктивная оплата 149₽ в тестовом режиме и выдача изображения с разбором и профессиями;
- предложение полного разбора за 990₽ через 20 секунд после выдачи результата с переходом в личный Telegram;
- изолированный SSH/SOCKS-шлюз для Telegram API на серверах без стабильного прямого маршрута;
- повторная выдача сохранённого платного аватара через `/profile`;
- AES-256-GCM для персональных полей и HMAC-SHA256 для индексов;
- `/stats`, `/delete_my_data`, публичные `/privacy`, `/terms`, `/source`, `/healthz`.

## Локальный запуск

Требуется Python 3.11 или 3.12.

```bash
python -m venv .venv
. .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
python scripts/build_geonames.py data/cities.sqlite3
money-profile-bot
```

Для создания трёх 32-байтных ключей:

```bash
python scripts/generate_keys.py
```

## Защитные блокировки production

Конфигурация `APP_ENV=production` не запускается без реквизитов оператора, утверждённого срока
хранения платёжного журнала, финальной версии юридических документов, подтверждения методики и
эталонных карт, всех ключей и реквизитов Robokassa. Отдельный флаг
`PAYMENT_PLATFORM_RISK_ACKNOWLEDGED=true` фиксирует принятое владельцем решение по оплате.

Методика в [metodika-denezhnogo-profilya.md](metodika-denezhnogo-profilya.md) пока имеет статус
черновика. Это не следует менять до профессиональной проверки астрологом.
