# Telegram-бот «Денежный потенциал»

Публичная AGPL-3.0 реализация Telegram-бота, который детерминированно рассчитывает
астрологический денежный профиль по локальной Swiss Ephemeris. В работающем приложении нет
LLM и вызовов OpenAI API.

## Возможности

- стартовый экран с явным согласием на обработку данных, без возрастного ограничения и без
  фиктивной записи подтверждения совершеннолетия;
- анкета с ветками точного, примерного и неизвестного времени рождения;
- одноразовое напоминание через час, если следующий шаг анкеты не пройден;
- локальный поиск GeoNames `cities500` и IANA timezone, включая ввод `Россия, Москва`;
- Плацидус с безопасной веткой без домов для полярных широт и неоднозначного времени;
- бесплатная карточка денежного аватара с кнопкой «Узнать силу» и автоматическим
  предложением через час, если кнопку не нажали;
- тестовая кнопка с ценовым ориентиром 149₽, явной пометкой об отсутствии списания и выдачей
  изображения с утверждённым описанием аватара и профессиями;
- предложение полного разбора за 990₽ по кнопке после платного результата либо автоматически
  через час, если кнопку не нажали, с переходом в личный Telegram;
- изолированный SSH/SOCKS-шлюз для Telegram API на серверах без стабильного прямого маршрута;
- повторная выдача сохранённого платного аватара через `/profile`;
- AES-256-GCM для персональных полей и HMAC-SHA256 для индексов;
- `/stats`, `/delete_my_data`, публичные `/privacy`, `/consent`, `/terms`, `/source`, `/healthz`.

## Локальный запуск

Требуется Python 3.11 или 3.12.

```bash
python -m venv .venv
. .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
python scripts/build_geonames.py data/cities.sqlite3
money-profile-bot
```

Для создания трёх 32-байтных ключей:

```bash
python scripts/generate_keys.py
```

## Защитные блокировки production

Текущая версия доступна всем пользователям в тестовом режиме с `APP_ENV=test` и
`PAYMENT_MODE=fake`. Списания и публичная продажа через бота отключены. Robokassa выбрана для следующего
этапа, но до production необходимо подтвердить соответствие
правилам Telegram, реализовать реальную оплату, чек и возврат, проверить юридические документы и
пройти релизные проверки.

[Методика версии 1.0](metodika-denezhnogo-profilya.md) и объединение двенадцати домов в десять
денежных аватаров подтверждены астрологом. Контрольные карты и пользовательский путь проверяются
отдельно перед публичным запуском.
