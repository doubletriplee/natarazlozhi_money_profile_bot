# Денежный аватар: сбой SSH SOCKS5 и переход на выделенный прокси

11 сентября 2026, проверка 06:38–06:43 UTC (09:38–09:43 МСК).

Пользователь сообщил о неработающих ботах и затем уточнил: не отвечает
«Денежный аватар», а «Не забудь» работает. Разрешил использовать прокси из
`C:/Users/kit/.ssh/telegram-proxy.txt` (расширение обнаружено при проверке).
Файл содержит учётные данные; содержимое не публикуется.

## Диагностика

- Германия сохранила IP 94.183.198.54. Оба VPS доступны, AmneziaWG имеет свежие
  handshake; запрос к Telegram через немецкий HTTP-прокси с RU возвращает 302.
- Money использовал другой путь: socks5://telegram-proxy:1080, SSH dynamic forwarding.
  getMe из контейнера приложения через этот путь не завершился за 30 секунд.
  В журнале были свежие TelegramNetworkError/TimeoutError при обработке сообщений.
- Это не подтверждает общий отказ Германии или всех ботов. Ne Zabud прошёл getMe,
  heartbeat свежий; оба немецких бота также прошли getMe. Кwork heartbeat свежий.
- Новый прокси проверен с RU по HTTP и SOCKS5; из контейнера Money три getMe
  через новый HTTP CONNECT подряд прошли за 1,56 / 0,29 / 0,29 секунды.
- Причина ложного зелёного мониторинга: Money проверялся через общий HTTP-прокси,
  а приложение работало через SSH SOCKS5. Проверка локального порта SOCKS5
  также не доказывала доступность Telegram через него.
- Точная первопричина деградации SSH SOCKS5 в этом восстановлении не установлена.

## Изменения

- Снимок прежних .env, compose.yaml и resource-check.sh:
  `/root/money-proxy-recovery-20260911/` на RU, каталог 0700.
- Только Money TELEGRAM_PROXY_URL переведён на авторизованный HTTP-прокси
  из указанного пользователем файла. Telegram HTTPS остаётся сквозным CONNECT.
  URL с учётными данными хранится в закрытой .env, не в Git.
- В действующем compose.yaml удалена только зависимость app от здорового
  telegram-proxy; существующие чужие изменения сохранены.
- Пересоздан только Money app из существующего образа, без обновления кода.
  Старый SSH-прокси не является текущим путём Money.
- Resource-check теперь выполняет getMe внутри Money с фактическим
  TELEGRAM_PROXY_URL и ограниченным временем проверки, без вывода секретов.
  Локальный шаблон также обновлён.
- Ne Zabud, Groq и остальные боты не переключались на новый прокси.
